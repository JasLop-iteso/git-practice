# Reporte del Laboratorio 9

## Introducción

El objetivo de este laboratorio es comprender cómo Git y GitHub permiten administrar el control de versiones de archivos y proyectos. A través de ejercicios prácticos, se crean, modifican y guardan diferentes versiones de archivos mediante commits. Además, se explora el uso de ramas (branches), la fusión de cambios (merge) y la sincronización entre repositorios locales y remotos.
## Evidencias

Durante la primera parte del laboratorio se realizaron diferentes actividades para comprender el funcionamiento de Git y GitHub. Se obtuvieron las siguientes evidencias:

- **Evidencia 1:** Configuración inicial de Git y verificación del entorno de trabajo.
- **Evidencia 2:** Historial de los tres commits realizados en el archivo `versions.txt`.
- **Evidencia 3:** Creación de una rama, modificación de archivos y fusión de cambios mediante `merge`.
- **Evidencia 4:** Repositorio `git-practice` en GitHub con el historial de commits.
- **Evidencia 5:** Sincronización de los cambios realizados en GitHub con el repositorio local mediante `git pull`.
